# Demo visualizations / 示例可视化

Generated HTML files are saved here. 生成出来的 HTML 可视化文件会保存在这里。

For a public teaching repository, keep only a small set of selected examples. This demo set is designed for humanities, social science, and interdisciplinary AI-related courses. 如果要公开上传到 GitHub，建议只保留少量精选示例。当前 demo 设计面向人文社科及跨学科 AI 相关课程。

Planned demo files. 计划使用的示例文件：

1. `01_解释一下著作权.html`
2. `02_How_does_big_data_recommendation_decide_what_content_to_show.html`

These examples are intentionally broad: one legal and cultural topic, one platform and recommendation topic, and one social impact topic. The first is in Chinese, and the second and third are in English, so instructors can show that the same visualization idea works across languages. 这些例子有意覆盖较宽的课堂讨论范围：一个法律与文化主题、一个平台与推荐主题、一个社会影响主题。第一个是中文，第二个和第三个是英文，方便教师展示同一套可视化思路可以跨语言使用。
