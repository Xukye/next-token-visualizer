# Demo visualizations / 示例可视化

Generated HTML files are saved here. 生成出来的 HTML 可视化文件会保存在这里。

For a public teaching repository, keep only a small set of selected examples. This demo set is designed for humanities, social science, and interdisciplinary AI-related courses rather than for one major only. 如果要公开上传到 GitHub，建议只保留少量精选示例。当前 demo 设计面向人文社科及跨学科 AI 相关课程，而不是只面向某一个专业。

Selected demo files. 选定的示例文件：

1. `01_解释一下著作权.html`: a Chinese example for discussing copyright, culture, and creative works. `01_解释一下著作权.html`：中文示例，用来讨论著作权、文化与创作活动。
2. `02_How_does_big_data_recommendation_decide_what_content_to_show.html`: an English example for discussing platform recommendation, media, and everyday data systems. `02_How_does_big_data_recommendation_decide_what_content_to_show.html`：英文示例，用来讨论平台推荐、传播媒介与日常数据系统。
3. `03_What_is_data_bias.html`: an English example for discussing data bias, social impact, and fairness. `03_What_is_data_bias.html`：英文示例，用来讨论数据偏见、社会影响与公平性。

These examples are intentionally broad: one legal and cultural topic, one platform and recommendation topic, and one social impact topic. The first is in Chinese, and the second and third are in English, so instructors can show that the same visualization idea works across languages. 这些例子有意覆盖较宽的课堂讨论范围：一个法律与文化主题、一个平台与推荐主题、一个社会影响主题。第一个是中文，第二个和第三个是英文，方便教师展示同一套可视化思路可以跨语言使用。
